  near-perfect rpm score is expected and is NOT independent evidence of rpm > native.
  The discriminating measurement is whether **native** hits these traps on probe-P1.

  cite-or-flag Gaastra or to surface "Vergaan Onder Corruptie" — it surfaced them
  unprompted. probe-P1 (native's prompt) NAMES both. So: native hitting 2–3 is
  partly prompt-assisted; native MISSING 2–3 despite being told is a strong signal.
- **Generous specimen:** rpm report is a 2-pass, human-confirmed-scope upgrade run —
  rpm's realistic high bar, not a cold single-shot.
- **Scope:** the report's "Design translation (iteration 16)" section is project glue
  native won't have; compare only the VOC-history body (§1–4 + Uncertainties + Sources).
