### Key Discoveries
- **Foreground subagents dump their entire final message into the parent
  context regardless of what they write to disk** — `guidance-aligner`
  returned 60–70k tokens twice this session despite a JSON-only
  contract. Delegating agents must mandate a terse final report (that's
  why `preflight.md` leads with "never paste raw scan output"). The
  contract is best-effort; expect imperfect compliance.
- The `guidance-aligner` *contradictions-only* mode produced a
  false-positive `CONTRADICTED` (`feedback_questions_at_end` vs
  session-end Inline mode) that the *full* run reclassified as `GAP`.
- The `/next` contradiction cache treats every `findings[]` entry as a
  contradiction, so the full guidance report must NOT be saved there —
  cache a CONTRADICTED-only payload instead.
